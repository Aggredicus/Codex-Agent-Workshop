# Reviewed Memory

Store concise, reusable lessons here only after they have enough evidence to deserve durable retrieval.

Do not use this directory for raw transcripts or automatic per-run logs.

A useful memory note should say:

```text
lesson:
evidence/source:
scope:
when it applies:
when it does not:
supersedes:
reviewed:
```

Prefer deleting/superseding stale instructions to accumulating contradictory guidance.
