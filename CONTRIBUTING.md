# Contributing to Codex Agent Workshop

Thanks for considering a contribution to the **open-source software**. Small, well-scoped improvements, tests, accessible UI work, research reproduction and documentation are welcome for review.

## Before you begin
1. Read the repository's `README.md`, `AGENTS.md`, `SPEC.md`, `WORKFLOW.md`, and `LICENSE`.
2. Look for a maintainer-approved issue labeled `good first issue` or `help wanted`. If no matching issue exists, ask for a small scoped task before implementing.
3. If you want help discovering suitable work, review the [Find Your Place draft](docs/volunteer/OPERATIONS.md) and the browser matcher in `docs/volunteer/index.html`.
4. Agree on acceptance criteria, risk, estimated scope, and a maintainer reviewer. Do not start work on private data, customer records, production credentials, or third-party intellectual property.

## Contribution workflow
- Fork or create an authorized short-lived branch; work without access to the default-branch credentials.
- Keep changes narrow and reversible. Preserve attribution, provenance, notices and applicable licenses.
- Run `caw validate` and `pytest -q` (plus any task-specific checks).
- Open a pull request linking the issue, describing tests actually run, observed limitations, affected files, licensing or dependency additions, and any approval requirements.
- Respect independent review; submitting a PR does not guarantee merge.
- Use GitHub public comments for project coordination, not sensitive information. Never post API keys or contact details in public issues.

Contributing does not imply employment, payment, exclusivity, or automatic commit rights. Do not interpret this repository as requesting unpaid work for a for-profit business. Business/client work requires a separately reviewed legal and commercial arrangement. No contributor is required to share a résumé, legal name, or private contact information to propose a public-source contribution.
