# Example — Permaculture Client Design Objective

## Goal

Prepare a concept-level residential permaculture design package for a West Michigan client, including site research, ecological design logic, planting strategy, important water considerations, and an initial cost/scope estimate.

## Suggested command

```bash
caw plan \
  --team permaculture-works \
  --goal "Prepare a client permaculture site design with planting strategy, site soil and water research, and cost estimate."
```

Or render a harness prompt:

```bash
caw prompt \
  --team permaculture-works \
  --goal "Prepare a client permaculture site design with planting strategy, site soil and water research, and cost estimate." \
  --mode multi
```

## Inputs to attach in a real project

- client intake,
- site address/general location as appropriate,
- site photos/maps/survey,
- measurements and known utility/ownership constraints,
- budget/timeline,
- relevant prior correspondence distilled into a brief,
- approved business pricing/scope references.

## Expected specialist outputs

- normalized site evidence + uncertainty list,
- ecological systems concept,
- planting strategy,
- water/earthwork constraints if relevant,
- estimate/scope assumptions.

## Review outputs

- scientific claim/uncertainty review,
- design coherence and client-experience review.

## Owner consequence gate

Human approval is expected before:

- sending the deliverable/proposal,
- making a binding price/scope commitment,
- presenting an engineering/permitting conclusion as authoritative,
- performing a live transaction or external account action.

The objective is to get the work *as close to final delivery as safely possible* before that gate.
