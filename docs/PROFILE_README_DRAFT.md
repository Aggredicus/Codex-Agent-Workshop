# Welcome — building tools together

I develop open-source software for agent-assisted development, local-first computing, interactive learning, and ecological design.

## Find your place in the projects
**Have a few hours and a useful skill to share?** I am preparing a contributor gateway that will help match self-reported Python, JavaScript, testing, design, security, GIS, documentation, and other skills with scoped work in my public software projects.

**Browse the proposed contribution areas:** [Find Your Place](https://aggredicus.github.io/Codex-Agent-Workshop/volunteer/) *(link becomes valid only after GitHub Pages is enabled and publication is verified).*

Explore:
- [Codex Agent Workshop](https://github.com/Aggredicus/Codex-Agent-Workshop) — human–AI coordination and development tools.
- [ConsciOS](https://github.com/Aggredicus/ConsciOS) — experimental inspectable cognitive architectures.

### Contributing
Choose a documented `help wanted` or `good first issue` ticket, or introduce yourself in the [Codex Agent Workshop issue tracker](https://github.com/Aggredicus/Codex-Agent-Workshop/issues). Public contributions are voluntary, scoped, reviewed and subject to each repository's license and contributing rules. There is no employment or paid-work offer.
