How to get involved

1. Explore a repository and read its README and license. 2. Ask for a clearly scoped public issue (or choose an explicitly labeled help wanted issue). 3. Agree on acceptance criteria, fork or branch as appropriate, and submit a pull request with evidence. 4. A maintainer reviews, responds, and handles integration.
